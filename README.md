# 🌤 Taoyuan Weather

桃園市 13 行政區天氣預報 GitHub Actions 專案。

目前版本：

**v2.2.0**

---

## 功能

- 桃園市 13 行政區
- 未來 3 天逐 3 小時預報
- 未來 7 天逐日預報
- 中央氣象署 CWA API
- Telegram Bot 推播
- GitHub Actions 自動執行
- 可指定日期
- 可指定行政區
- 支援只執行 API、不推送 Telegram
- Telegram 自動分割長訊息
